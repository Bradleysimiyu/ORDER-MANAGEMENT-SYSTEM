# Order Management System 🛒

The Order Management System is a web-based application designed to help businesses manage customer orders efficiently. It provides a user-friendly interface for customers to place and track orders, while administrators can manage products, orders, customers, and order status.

## Features

- 🛍️ Browse available products
- 🛒 Add products to cart
- 📦 Place and manage orders
- 👤 Customer/user dashboard
- 🛠️ Admin dashboard
- 📊 Manage products and orders
- 🔄 Track order status
- 📱 Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript
- Firebase

## Project Structure

The project contains two main sections:

- **User Dashboard** – Allows customers to browse products, add items to the cart, and place orders.
- **Admin Dashboard** – Allows administrators to manage products, orders, and customers.

## Project Status

🚧 **Currently under development.**

## Purpose

The main goal of this project is to provide a simple and efficient system for managing online orders while improving the experience for both customers and administrators.
